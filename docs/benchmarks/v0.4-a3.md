# Dirloom v0.4.0-a3 verify benchmarks

Local baseline for one snapshot load, one live fingerprint, and a typed fingerprint comparison. Times are not CI gates. The architectural gate is a single observation and a single `identity.Compute` on the live artifact, not a second filesystem walk or a node-by-node diff.

## Notes

- `VerifyValidatedFromSource` calls `Observe` once and `identity.Compute` once. Equality is typed fingerprint comparison.
- The filesystem benchmark does not serialize a second snapshot and does not walk the tree again to diff nodes.
- No flaky wall-clock threshold is asserted in CI.
