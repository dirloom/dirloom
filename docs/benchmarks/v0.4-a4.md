# Dirloom v0.4.0-a4 structural diff benchmarks

Local baseline for one structural comparison: Identity Projection v1 on both
in-memory artifacts, the two-way merge over sorted records, and model
validation. No filesystem scan is involved; observation cost is measured by
the v0.4.0-a3 verify benchmarks. Times are not CI gates. The architectural
gate is one projection per artifact and an O(N+M) merge, not a matrix
comparison.

## Notes

- `Compare` calls `Observe` once per source and `identity.ProjectV1` once per
  observed artifact, then merges the two sorted record slices in a single
  pass and validates the resulting model.
- Allocations scale with nodes plus changes; there is no per-pair matrix.
- No flaky wall-clock threshold is asserted in CI.
